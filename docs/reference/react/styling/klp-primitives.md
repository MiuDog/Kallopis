# klpPrimitives

React · 0.1 · 未發布 npm · 語意風格

## 主要職責

正式規範產生的 primitive 值集合；不在此文件維護另一份設計數值。

## 公開入口

- `@kallopis/react`

## 速成使用

前置：[平台接入](../quickstart.md)。以下為接入片段；必要資料由產品提供。

```tsx
import { klpPrimitives } from '@kallopis/react';

const productReference = klpPrimitives;
```
