# klpThemes

React · 0.1 · 未發布 npm · 語意風格

## 主要職責

正式規範產生的各模式語意 token 集合。

## 公開入口

- `@kallopis/react`

## 速成使用

前置：[平台接入](../quickstart.md)。以下為接入片段；必要資料由產品提供。

```tsx
import { klpThemes } from '@kallopis/react';

const productReference = klpThemes;
```
