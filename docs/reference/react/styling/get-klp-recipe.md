# getKlpRecipe

React · 0.1 · 未發布 npm · 語意風格

## 主要職責

取得正式生成的元件配方；未知 ID 會拒絕，不負責任意 DOM 呈現。

## 公開入口

- `@kallopis/react`

## 速成使用

前置：[平台接入](../quickstart.md)。以下為接入片段；必要資料由產品提供。

```tsx
import { getKlpRecipe } from '@kallopis/react';

const recipe = getKlpRecipe('button-base');
```
