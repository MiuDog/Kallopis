# klpStyleParameters

React · 0.1 · 未發布 npm · 語意風格

## 主要職責

風格參數的公開 metadata，供產品建立合法設定介面。

## 公開入口

- `@kallopis/react`

## 速成使用

前置：[平台接入](../quickstart.md)。以下為接入片段；必要資料由產品提供。

```tsx
import { klpStyleParameters } from '@kallopis/react';

const productReference = klpStyleParameters;
```
