# KlpTokenValidationBanner

Flutter · Experimental · 內容元件

## 主要職責

Token 圖形驗證結果，不自行推導循環或型別相容性。

## 公開入口

- `package:kallopis/kallopis_experimental.dart`

## 速成使用

前置：[平台接入](../../quickstart.md)。以下為接入片段；必要資料由產品提供。

```dart
import 'package:kallopis/kallopis_experimental.dart';

// 由產品提供必要資料；可選參數沿用下表預設。
KlpTokenValidationBanner createExample(String title, String message, bool valid) => KlpTokenValidationBanner(title: title, message: message, valid: valid);
```
