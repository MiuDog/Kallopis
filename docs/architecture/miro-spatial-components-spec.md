# Miro 空間元件蒸餾

狀態：2026-09-11 初步功能契約。M 編號為研究項目，不表示已實作或涵蓋 Miro 全部服務。專用圖表、整合與平台差異仍待逐頁核對。

## 來源與設計界線

官方 [物件操作](https://help.miro.com/hc/en-us/articles/360017730953-Working-with-objects)、[內容整理](https://help.miro.com/hc/en-us/articles/360017730973-Structuring-board-content)、[Frames](https://help.miro.com/hc/en-us/articles/360018261813-Frames)、[Connection lines](https://help.miro.com/hc/en-us/articles/360017730733-Connection-lines) 是本輪參照。

連線文件說明直線、折線、曲線、箭頭、文字與端點重接，且明列 frame 不能直接當連線目標。這支持「不同物件有不同能力資格」的設計方向；Kallopis 的實際資格集合仍由自己的契約決定。

以下資料模型與拒絕規則是 Kallopis 提案，不代表 Miro 原始碼設計。

## 能力清單

| ID | 能力 | 必要資料／資格提案 | 驗收重點 |
|---|---|---|---|
| M01 | 空間文字 | 文字文件參照、幾何、可編輯資格 | 文字編輯沿用筆記核心；移動與選字不互搶 |
| M02 | 便條 | 內容、內容色彩角色、尺寸規則 | 溢出與文字縮放有唯一規則；不注入元件樣式 |
| M03 | 圖形 | 形狀種類、幾何、可選文字及接點資格 | 命中與外觀一致；不接受任意繪製回呼 |
| M04 | 資料卡片 | 資料參照、顯示欄位、可用操作 | 資料載入／錯誤／唯讀都有明確投影 |
| M05 | 圖片與附件 | 資產身分、尺寸、替代描述、載入狀態 | 缺檔與未授權可辨識；縮放不丟失原始來源 |
| M06 | 嵌入與預覽 | 註冊 provider、資料參照、互動模式 | 畫布手勢與內嵌內容互動有明確交接 |
| M07 | 自由筆跡 | C 系列筆跡節點與核心參照 | 與手寫共用資料及操作，不建立第二份筆跡 |
| M08 | Frame | 邊界、成員關係、標題、呈現次序 | 包含關係不同於群組；移動成員政策明確 |
| M09 | 群組 | 成員 ID、共同變換、可解組資格 | 防循環；跨鎖定／跨容器組合規則可驗證 |
| M10 | 連線 | 兩端點、錨點、路徑種類、可連接資格 | 禁止連到無資格物件；刪除端點有確定處理 |
| M11 | 端點與路徑調整 | 附著／自由端點、控制點、核心路由 | 拖移物件保持合法附著；取消不殘留暫存線 |
| M12 | 連線標籤與插入節點 | 文字參照、相對位置、插入交易 | 分割連線原子完成；標籤定位不依顯示縮放漂移 |
| M13 | 心智圖 | 樹節點、父子關係、布局模式 | 禁止循環與多父；自動布局由單一核心演算法負責 |
| M14 | 表格與結構化容器 | 行列、cell 資格、資料投影 | 任意空間物件不能直接塞入 cell |
| M15 | 專用圖表與符號庫 | 元件註冊、接點及內容資格 | 每種圖表分開盤點；不能用一個任意 Widget 擴充口替代 |
| M16 | 單選、多選與框選 | 選取投影、模式、幾何版本 | 唯讀、隱藏、鎖定有一致規則 |
| M17 | 移動、調整尺寸與旋轉 | 操作資格、初始幾何、變換意圖 | 不支援操作不顯示把手；取消與衝突可恢復 |
| M18 | 對齊、分布與吸附 | 目標集合、參照範圍、候選投影 | 結果不受物件遍歷順序影響；鎖定物件規則明確 |
| M19 | 層序與鎖定 | 順序、鎖定狀態、有效操作集合 | 選取提示不改寫永久層序；不繞過權限 |
| M20 | 導覽與聚焦 | viewport、目標邊界、frame 順序 | 空白／極大範圍／縮放上下界都有有效結果 |
| M21 | 註解與協作游標 | 穩定錨點、使用者投影、暫時狀態 | 人員離線與目標刪除可處理；不把 presence 當文件內容 |
| M22 | 搜尋、清單與鍵盤替代 | 可定位 ID、可讀名稱、可用操作 | 不依靠視覺找物件；能以鍵盤聚焦和操作 |
| M23 | 複製、貼上與匯出 | 子圖、資產參照、格式能力 | 新 ID 與內部連線重映射一致；外部參照策略明確 |
| M24 | 中斷、衝突與撤銷 | session、操作序號、預期版本、核心交易 | 相同操作不重複提交；錯誤不能被當成已保存 |

## 組裝契約

空間容器只接受具備空間放置資格的節點；連線端點另要求可連接資格；frame 的成員 slot 與群組成員集合分開定義。元件可同時具備可選取、可移動、可調整尺寸、可容納、可連接資格，但不因「可顯示」自動取得其他資格。

這些目前是設計名稱，尚未定案為 Dart 介面。公開介面需同時定義靜態 slot 約束與動態驗證：即使類型合法，失效 ID、循環關係、版本過期與越權操作仍要拒絕。

共用文字引用 N 系列；手寫引用 C 系列；不要為空間文字另造文字核心。Kallopis 呈現與輸入，核心持有空間幾何、關係、選取與歷史，產品提供資料及協作服務。暫時拖曳預覽不能成為第二份文件權威。

## 執行順序與範圍

先驗證 M16–M20、M24 的空間操作閉環，接入 M01、M03、M05、M08，再加入 M10–M12 連線與 M13 等功能。連線屬完整研究及架構範圍；是否在 Planist 首版啟用另行決定。

畫布內移動物件不等同於工作區欄位重排。使用者已決定首版工作區可拉伸、不可自訂排版，不能藉由 M17 擴張為可移動左右側欄。

待補：便條、卡片、表格、專用圖表各自官方細節；平台功能矩陣；內容色彩與圖形樣式的資料契約；核心連線路由、空間索引與大型文件效能證據。尚未查證的能力不得宣稱已獲目前引擎支援。
