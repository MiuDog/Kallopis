# Concepts 手寫體驗蒸餾

狀態：2026-09-11 初步功能契約。下列 C 編號是研究與驗收項目，不是已存在的公開 API；尚未完成 Windows、Android、iPad 實機比對。本文不宣稱完整復刻 Concepts。

> 2026-09-13 使用者確認分期：第一版不要求 Concepts 等級的筆刷、壓感與精準編輯，後續版本會加入。本文相關進階項目保留為後續需求，不是第一版交付門檻；第一版沿畫布引擎的基本繪圖能力接入。這不代表整份 C 清單已取消，也不代表其餘畫布能力一律延後。分期以 [筆記總入口](note-components-plan.md) 為準。

## 來源與設計界線

官方 [工具手冊](https://concepts.app/en/manual/brushes-and-tools) 描述筆刷、選取、修改筆跡，以及 Slice 與 Mask 的差異。[選取手冊](https://concepts.app/en/manual/selection) 說明套索、單筆選取、圖層及鎖定篩選，以及縮放與維持筆寬的伸展。[精準工具手冊](https://concepts.app/en/manual/precision-tools) 涵蓋格線、吸附、比例與形狀輔助。

以下資料模型、限制及失敗處理是 Kallopis 提案，不代表 Concepts 內部實作。平台功能不能由此手冊推定全部相同。

## 能力清單

| ID | 能力 | Kallopis 契約提案／必要資料 | 驗收重點 |
|---|---|---|---|
| C01 | 筆與手指分流 | 裝置能力、pointer 身分、目前工具、單一手勢擁有者 | 同時輸入不重複落筆；掌觸不移動畫布 |
| C02 | 筆跡取樣 | 時間、位置、壓力、傾斜及各通道可用性 | 缺少壓力不能偽裝成真實量測；亂序資料處理明確 |
| C03 | 筆跡預覽與提交 | stroke ID、操作序號、座標版本、核心回覆 | 預覽換成正式筆跡不閃爍、不重複；預覽不是已保存 |
| C04 | 平滑與延遲 | 由核心統一處理軌跡演算法及有效參數 | 同一輸入可重播；呈現端不另造不同軌跡 |
| C05 | 固定寬度筆 | 工具語意、核心筆跡模型 | 縮放後世界尺寸與螢幕尺寸語意不能混用 |
| C06 | 壓感／速度筆 | 工具資格與能力投影 | 不支援通道有明確降級；變更工具不修改已提交筆跡 |
| C07 | 鉛筆／標記／紋理筆 | 材質語意、筆刷資產身分、核心合成能力 | 缺資產可辨識；不同平台外觀一致性待實測 |
| C08 | 工具預設與切換 | 註冊工具集合、目前工具、可用狀態 | 不接受任意 painter；筆劃中切換的處置須定義 |
| C09 | 切除筆跡 | 路徑、目標範圍、刪切操作 | 切割交由核心；不對無切割資格的圖片套用 |
| C10 | 非破壞遮罩 | 遮罩 ID、所屬範圍、合成次序 | 可撤銷與刪除遮罩；不能冒充刪除原始筆跡 |
| C11 | 套索 | 路徑、完整包含／相交策略、圖層範圍 | 邊界判定由核心一致處理；鎖定規則不旁路 |
| C12 | 單筆選取與增減 | 目標 ID、目前選取版本、操作種類 | 不將螢幕座標當永久筆跡 ID |
| C13 | 筆跡屬性取樣 | 已選筆跡的可公開工具屬性 | 取樣內容屬性不能改寫應用程式 theme |
| C14 | 群組、複製與鎖定 | 成員 ID、群組關係、操作權限 | 防循環群組；複製產生新 ID；鎖定仍可被輔助工具描述 |
| C15 | 移動、旋轉與翻轉 | 初始幾何版本、變換意圖 | 中途取消回復；過期版本不套錯對象 |
| C16 | 縮放與維持筆寬伸展 | 明確的變換模式 | 同一控制器不可默默改變筆寬規則 |
| C17 | 變形與局部修整 | 工具資格、控制點、核心幾何支援 | 不支援時不可只畫出可操作把手 |
| C18 | 圖層 | 穩定 ID、順序、可見、鎖定、作用中層 | 隱藏、鎖定與作用中是不同狀態；歷史操作一致 |
| C19 | 畫布平移縮放旋轉 | 單一 viewport 變換及其版本 | 取樣與命中使用同一反變換；非法縮放拒絕 |
| C20 | 格線及吸附 | 格線種類、吸附候選、啟用狀態 | 格線呈現與吸附幾何不分岔；可暫時停用 |
| C21 | 比例與量測 | 世界單位、顯示單位、有效精度 | 顯示捨入不能回寫幾何；單位變更不使筆跡跳位 |
| C22 | 形狀輔助與辨識 | 輔助器資格、辨識候選、接受操作 | 辨識失敗保留原筆跡；不可靜默覆寫 |
| C23 | 匯入與匯出 | 資產參照、格式能力、工作狀態 | 失敗／取消可見；輸出完整性由核心與產品服務驗證 |
| C24 | 中斷與撤銷 | session、交易、核心歷史投影 | 失焦、裝置斷線、取消、重試不得造成半筆跡或重複提交 |
| C25 | 無障礙替代操作 | 工具名稱、可用操作、數值調整入口 | 不能把套索或雙指手勢當唯一入口 |

## 組裝與權威

消費端安裝手寫功能時提供核心 adapter、工具註冊集合與資料參照，再把合格手寫節點放入可接受畫布的 slot。不能提供 Flutter Widget、Painter、任意筆跡回呼或第二套選取狀態。

Kallopis 負責工具列、游標、選取提示、輸入轉譯、無障礙與生命週期；核心負責筆跡、命中、幾何、交易及歷史；產品負責檔案位置、分享與保存政策。上述分工尚需逐項對照現有 Krepis 能力，缺少的核心功能不能靠 UI 假實作補齊。

工具 UI 的色彩、尺寸與字體由 Kallopis 決定。使用者創作內容的墨色、筆寬則是另一個需要明確定義的資料契約：是否允許自由色彩、僅語意墨色或註冊色票仍未定案，不能藉此放寬消費端元件樣式限制。

## 執行順序與未定事項

先做 C01–C04、C19、C24 的輸入與座標閉環，再接 C05、C11–C12、C18 的基本手寫，最後展開筆刷材質、精準工具與變形。每一階段都要實際筆輸入證據，純資料測試不能代替延遲與掌觸體驗驗收。

待確認：各平台能力矩陣、核心筆刷／切割／遮罩支援、內容墨色契約、落筆期間失焦和工具切換政策。Pencil hover 只列能力偵測候選，使用者尚未決定採用，不可設為首版必要操作。
