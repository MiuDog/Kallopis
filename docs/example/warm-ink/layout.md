# 布局及互動規則

## 畫面組合

1. 頂部品牌與產品工作空間名稱。
2. 暖黃色主區塊：左側主標題、說明及主要操作，右側三欄兩列功能方塊。
3. 最近內容標題與「全部／已加星號」分段切換。
4. 深灰列表：縮寫方塊、名稱與輔助資訊、開啟按鈕。
5. 操作後顯示內容預覽面板；底部顯示目前項目數與示例標記。

此組合是示例產品布局。共用風格不擁有分類名稱、功能順序或業務資料。

## 響應式

主區塊使用 `1.1fr 1fr` 雙欄。在寬度不大於 650px 時改為單欄、主區塊內距 25px、欄間距 24px，畫布內距改為上下 20px／左右 16px。功能方塊仍維持三欄。頂部、列表工具列與頁尾允許換行。列表內容欄使用 `minmax(0, 1fr)`。

## 狀態

- 點選分類：更新選中狀態、列表、標題與項目數，關閉已開啟的預覽；保留目前星號篩選。
- 方塊 hover 與 selected 共用深黃色表面，selected 額外以右上角圓點與 `aria-pressed` 表達。
- 點選篩選：更新列表、按鈕 `aria-pressed` 與項目數。沒有符合資料時顯示空狀態。
- 開啟項目或主按鈕：顯示相應名稱的示例預覽；關閉按鈕隱藏面板。這不是產品詳情頁或資料載入 API。
- 所有操作使用原生 button，保留瀏覽器 focus 表現。粗指標裝置按鈕最小高 44px。
- 項目數與預覽以 `aria-live="polite"` 通知。星號與選中圓點提供顏色之外的辨識。

未定義的 disabled、錯誤、載入與表單狀態不屬於這次確認範圍。後續擴展時需補齊契約。
