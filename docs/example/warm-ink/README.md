# 暖墨 Warm Ink

2026-10-16 使用者確認並要求收藏。此版本已包含「按鈕與方塊圓角各增加 2px」的修改。

## 風格定位

黑色畫布、暖黃主區塊、同色階功能方塊與深灰內容表面。以扁平色塊、微圓角、強文字層級及規律間距建立辨識；不使用陰影與漸層。

這是消費者可參考的獨立風格收藏，不取代既有風格，也尚未提供 Flutter／React 公開風格選擇 API。後續正式整合須經既有 semantic resolver 與框架契約實現，不要求產品複製示例內部樣式。

## 示例情境與責任

虛構的「木禾設計」團隊以工作空間查看專案、筆記、素材、任務、靈感與封存。這些分類、文案、排序及資料只屬於示例產品；不是 Kallopis 強制的功能組合。示例資料僅存在記憶體，重新載入會重設。
