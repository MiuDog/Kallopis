# 暖墨風格 token

本表記錄已確認示例的值。`preview.html` 是可操作來源；未來正式樣式套件應將這些角色映射到 Kallopis semantic style，不能把本文件當成第二份全域 theme。

## 色彩

| 角色／來源 | 值 | 用途 |
| --- | --- | --- |
| `--wi-bg` | `#080808` | 畫布 |
| `--wi-panel` | `#242428` | 內容區、預覽面板、分段控制底 |
| `--wi-text` | `#f6f5f2` | 深色表面主要文字 |
| `--wi-muted` | `#b5b5bd` | 深色表面次要文字 |
| `--wi-yellow` | `#f4dc70` | 主區塊、品牌點綴 |
| `--wi-tile` | `#e9c654` | 方塊預設表面 |
| `--wi-active` | `#dcae38` | 方塊 hover 與 selected 同色 |
| `--wi-ink` | `#11110e` | 黃色與淺色表面文字 |
| 主按鈕表面 | `#fffdf5` / `#f8edc0` | 預設／hover |
| 分段選中面／文字 | `#f4f1e7` / `#161615` | 已選篩選 |
| 項目縮寫表面／文字 | `#39393e` / `#eee9d7` | 列表小方塊 |
| 列分隔線 | `#39393e` | 僅分隔相鄰列表項目 |
| 次按鈕表面 | `#35353b` / `#48484e` | 預設／hover |

## 形狀

| 角色 | 圓角 |
| --- | --- |
| 主區塊、列表與預覽面板 `--wi-radius` | 12px |
| 功能方塊 | 7px |
| 主／次按鈕 | 6px |
| 項目縮寫方塊 | 6px |
| 分段控制外層 | 7px |
| 分段控制內部按鈕 | 5px |

上述小元件數值已含使用者要求的 +2px；大容器維持 12px。沒有投影、立體高光或漸層。

## 字體

示例字體鏈為 Arial、Microsoft JhengHei、sans-serif，沒有捆綁字型資產；正式跨框架實作須保留各框架既有字型資產 ownership。

| 角色 | 字級／粗細 | 補充 |
| --- | --- | --- |
| 正文 | 14px / 400 | 行高 1.5 |
| 主標題 | 36px / 800 | 行高 1.25、字距 -1.5px；窄版 31px |
| 品牌文字 | 20px / 800 | 字距 -0.7px |
| 區域標題 | 18px / 700 | 列表、內容預覽 |
| 方塊縮寫 | 28px / 700 | 行高 1.15、字距 -1px |
| 列表縮寫 | 16px / 700 | 40 × 40px 方塊內 |
| 項目名稱／主按鈕 | 14px / 700 | 主操作與標題 |
| 次要資訊 | 12px / 400 | 列表說明、工作空間名稱 |
| 方塊名稱／頁尾 | 11px / 400 | 輔助資訊 |
| 英文引題 | 11px / 700 | 字距 1.5px |

## 間距與尺寸

`--wi-gap` 為 12px 功能方塊間距。主區塊內距 34px、雙欄間距 32px；畫布內距上 24px、左右與下 30px。列表左右內距 22px、列上下 18px、欄間距 15px。分段控制內距與間隙皆為 4px。方塊最小高 90px，主按鈕最小高 44px。
