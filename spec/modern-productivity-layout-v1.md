# 現代風生產力佈局 v1

正式名稱：**現代風生產力佈局**（**Modern Productivity Layout**）。

穩定識別：`modern-productivity-layout`。

擁有模組：Kallopis 共通佈局規範。階段：DEFINE／0→1。目標版本：可迭代公開模板 v1。

狀態：DEFINE READY（可迭代公開模板）。使用者已指定名稱、唯一左側欄、內部按鈕列切換，以及可及時調整細節並供 consumer 快速套用的模板；框架 API、互動預覽與起始範例尚未實作。本次不新增獨立的側欄裝飾規則，外觀沿用現行正式語意。

## 模板交付目標

模板是可重用的共通視覺組合：公開元件提供結構，公開參數與既有 semantic override 提供細節調整，起始範例提供產品接線，互動預覽提供迭代回饋。各作品直接引用套件公開入口，替換自身內容與事件；不需複製元件內部樣式。

同一模板支援共用預設的版本化迭代與單一作品的局部覆寫。作品不因另一作品調整而改變；更新共用模板需明示相容性與遷移，不能靜默改動既有選取或草稿。

## 用途與角色

供多個個人作品共用的生產力工作區佈局。左側欄整合導航、列表、工具與原右側欄的輔助功能；使用者透過側欄內部的按鈕列切換目前呈現的功能內容。產品擁有具體功能、資料與事件。

外層只有兩個相鄰版面：左側全高 `sidebar` 與右側 `stage-region`。右區由上方 `header` 與下方 `stage` 組成；右區是主工作內容，不是右側欄。Header 只服務右區，左側欄不為它預留對齊空白。

左側欄內具有 `switcher` 按鈕列與 `active-panel` 功能內容區。按鈕列切換同一左側欄中的功能；原先屬於右側欄的功能全部進入這套切換機制。本佈局沒有獨立右側欄、右側輔助面板槽位或切換後重新出現的右側欄。

## 既有契約與接續

視覺值由 [正式配方](../docs/design-tokens/recipes.md) 擁有；現有 `frame-sidebar`、`stage-frame`、`surface-stage` 與按鈕配方供後續框架對應參照，尚不指定新公開型別或內部組裝方式。維護依 [通用視覺規範維護規則](../docs/design-tokens/maintenance.md)，產品／共通規範／框架責任依 [跨框架核心目標](multi-framework-design-system.md)。

本契約限定本佈局的組合規則，不移除 Kallopis 其他佈局可使用的右側欄元件，也不擅自遷移個別作品。產品接入時列出原右側欄功能與左側入口的對應，驗收每項功能可透過按鈕列取得。

本次能力地平線為 v1 完整公開模板：共通角色、幾何、切換、公開細節調整、雙框架起始範例與真實互動預覽；套件元件、consumer 範例與文件接入均屬本次交付。窄版重排、收合與拖曳 resize 仍屬後續選項。可觀察驗收為左側全高、header 只屬於右區、stage 使用剩餘空間、沒有右側欄，以及左側功能切換與多作品引用一致。感官品質由使用者接受。

DEFINE 無 open P1。r2 PLAN 已將 PSS-10～14 分配到框架、consumer 預覽與公開文件的 module contracts、write_paths 及驗收；完整模板尚未實作，不能以核心元件或架構文件宣稱已交付。產品資料權威及既有樣式來源保留。
